Revised CHARRMPASS Dual-Range RFID Architecture v4.0 Concept

Campus Entry & Exit Monitoring for both Walking Pedestrians and Vehicles using Close-Range & Long-Range RFID.

2 RFID MODES ACTIVE
1. PEDESTRIANS 13.56 MHz / 125 kHz
Close-Range RFID Reader / ID Tag

Walking students, faculty, staff, and visitors tap or scan their ID card at pedestrian turnstiles and walkway readers upon entering or exiting campus.

Pedestrian Scan Flow:
Student approaches reader → Taps/scans RFID card → ESP32 reads UID → CHARRMPASS verifies user → ENTRY / EXIT Logged
2. VEHICLES 900 MHz UHF Long-Range
Long-Range RFID Reader / Windshield Tag

Motorcycles, cars, SUVs, and delivery vans with windshield/headlight UHF tags are automatically detected at a distance for automated campus gate monitoring (no barrier required).

Vehicle Detection Flow:
Vehicle approaches gate → Long-range UHF detects tag → ESP32 receives tag → CHARRMPASS verifies vehicle → ENTRY / EXIT Logged
Unified Database Distinction
Database records distinguish user_type (Pedestrian / Vehicle), rfid_type (Close-Range / Long-Range), and direction (Entry / Exit).
